# Player Locator HUD

Enhance your Minecraft experience with a custom HUD overlay showing player locations.

## Features

- Custom HUD overlay on the XP bar
- Directional markers (N/S/E/W) for player location

## Requirements

- Minecraft 1.12.2
- Forge 1.12.2-14.23.5.2859

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/player-locator-hud/releases).
2. Place the downloaded JAR file in your Minecraft `mods` folder.
3. Launch Minecraft with Forge.

## Usage

Once installed, the HUD overlay will automatically appear on the XP bar, displaying directional markers (N/S/E/W) to help you locate yourself in the game world.

## Configuration

The mod does not have any configuration files. The HUD overlay is fixed on the XP bar and cannot be moved or customized.
